# Recall — 按需召回技能

## 何时使用

- 用户提到"上次/之前/我们说过/怎么处理的"——先搜再答，禁止凭上下文残影编造。
- 接手旧任务前，想捞回当时的决策与坑。

## 怎么用

```bash
python <skill_dir>/recall.py 关键词1 [关键词2 ...] [--days N]
```

- 多关键词 = 同一行同时包含（AND）。给 2-3 个最具体的词，别堆词。
- 命中后：引用必须带 `文件:行号`；需要更多上下文就 Read 该行的前后。
- 0 命中：如实说"档案里没搜到"，换一组词再试一次，仍没有就承认不知道。

## 前置

数据源配置 `recall-sources.txt` 需存在于工作目录或用户目录（格式见 README）。
没有配置时先引导用户创建，不要瞎猜路径。

## 家规

- 永不把敏感目录（图片视频、密钥文件）加进数据源。
- 本技能只读不写；搜到 ≠ 核实，关键结论仍须按出处二次确认。
