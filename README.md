## 这是什么

**M 平台** = 自建的多智能体协作平台，长这样：

```
浏览器（Deep Agent UI）
   │  注册 / 登录 / 四档确认 / 顶栏快捷开关
   ▼
office API（FastAPI · 守卫+审计+设置单一真源）
   │
   ▼
米娅（Supervisor 主对话 · 魔搭千问）
   │  派活（官方 AsyncSubAgent）
   ▼
牛马部门（coder / researcher / planner / archivist / scribe / visual …）
   │  只执行不请示，结果沿链上报
   ▼
审计账本（每一笔批准/拦截/派活/轮换全留痕）
```

- **主人注册即开**：打开页面谁先注册谁主人（管理员用户名必须亲手起），注册后全平台上锁
- **四档确认**：计划模式 / 变更前确认 / 自动编辑 / 完全访问——四档自由切，改完即时生效
- **批准卡**：需要主人批准的动作弹卡展示参数预览（批内容不批工具名），批准=按钮扣章
- **机器安全门**：高危形态（密钥字面量/全盘 find/路径锁定）确定性拦截，任何档位都在
- **审计账本**：档位变更、批准、拦截、登出、密钥操作全落 JSONL
- **后台任务**：主管派活给异步部门，完成自动汇报，任务状态在任务面板不混对话流
- **邮件工具**：智能体信箱体系（ClawEmail 双通道：ajax 正门 + IMAP 授权码门）

## 技术栈

| 层 | 件 |
|---|---|
| 前端 | Next.js 15 + React 19（Deep Agent UI，官方 deep-agents-ui 改造） |
| 编排 | langgraph 1.2.12 + langchain 1.4.2 + deepagents 0.7.19 |
| 门 | 自研 ConfirmGateC1（官方 HumanInTheLoopMiddleware 包装：批量卡+两钩子+机器安全门） |
| 守卫 | m-guard（密钥/密码/验证独立进程，fail-closed） |
| 数据 | settings.json 单一真源 + secrets 卷（明文不入 settings） |
| 测试 | vitest 58 + 门单元 31 + 压力 95 + rev 竞态 6 + 守卫 100 |

## 安全模型（行为即规格）

- **fail-closed 默认**：守卫不可达=写路径全 503，宁拒不裸
- **越权兜底也删**：不留"暂用第一个"式的暗兜底
- **密码找回最小破坏**：只改门锁不动数据（对标 OWUI 数据流等价）
- **设置防撞车**：`_rev` 版本号全入口覆盖，后台修改=409 拒绝旧版请求
- **毒化自愈**：settings.json 半写损坏自动从备份恢复+原件留证+大声报错，绝不静默兜底

## 兼听则明的实践

每一轮变更都走"**判词 → 对账 → 真机**"三层闭环：多个独立评审员（不同平台不同家族的智能体）盲审源码出判词 → 交叉对账收敛分歧 → 主会话修复 → 全员回归+真机验证。本仓 r29→r33 六轮变更全部经此流程，最高一轮 21 项发现从判词到闭环 6 小时。
